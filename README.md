# Fiona Lippert

A single-page personal website. Edit the words in `content.md` using GitHub’s pencil button, then commit the changes. Keep the four `##` section headings. Name and affiliation live in `profile.json`, as does the design credit in the footer (`designer`).

## Publish with GitHub Pages

The site lives in Fiona’s repository `FionaLippert/FionaLippert.github.io` and appears at https://fionalippert.github.io/. Casper maintains it as a collaborator.

One-time setup, done by Fiona as the owner:

1. Create a public repository named exactly `FionaLippert.github.io`, with no README or other files.
2. In **Settings → Collaborators**, invite `cvanelteren` (Casper accepts the invitation).
3. In **Settings → Pages**, choose **GitHub Actions** as the source.

After that, every push to `main` runs **Actions → Publish site**, which builds the page and publishes it within a minute or two. It can also be started by hand from the Actions tab. [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).

The globe at the top is drawn on a canvas by `assets/globe.js`, from the data in `assets/globe-data.js`. While the first screen is pinned, scrolling turns the Earth from the Middle East to Africa, moves flocks of birds south along their routes and lets a satellite record a swath of reflected sunlight. Weather-radar stations over Western Europe light up as the flocks pass. Visitors who ask their system for reduced motion get a single still frame instead. To preview one frame, open `index.html?progress=0.5` (any value from 0 to 1). `assets/globe-data.js` is generated by `mockups/fiona_globe_data.py` in the parent folder from Natural Earth coastlines; the satellite swath, radar network and migration routes are schematic. The Google Scholar and GitHub buttons next to it take their links from `profile.json`. Research entries cycle through the three icons in `assets/icons` (plain SVG files), so a fourth entry reuses the first.

## Custom domain

For a domain you own, add it in **Settings → Pages → Custom domain**, follow [GitHub’s DNS instructions](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site), then enable **Enforce HTTPS**. The `github.io` address is included; a custom domain is purchased separately.

## Local preview

Open `index.html` with the `assets/` folder beside it. After changing source files, run `node build.mjs` with Node.js 22 or later. No package installation is needed. The **Rebuild page** workflow also refreshes the stored `index.html` after edits made on GitHub; the published site is always built fresh from the source files.

Photo credits, research sources and font licences are recorded in `SOURCES.md` and `assets/`. Review the biography and portrait reuse permission before launch.
